## Folgerungen

1. **Keine Vergleiche als Bewertung.** „praxissoftware vergleich“ ist die größte Nachfrage. Die Seite bewertet keine
   Software (Profilregel); sie kann aber vergleichen, was belegt ist: Verbreitung, Wachstum, Zulassungen,
   Betriebssysteme. So ist die Säulenseite aufgebaut; im Text das Wort „Vergleich“ nur mit diesem Zuschnitt verwenden.
2. **Keine Kannibalisierung:** Säulenseite = „Übersicht“, Post 1 = „Marktanteile“, Post 2 = „Hersteller“.
3. **Neue Idee mit Nachfrage: Praxissoftware nach Fachrichtung** („praxissoftware hausarzt vergleich“,
   „allgemeinmedizin“). Die KBV veröffentlicht Installationsberichte je Arztgruppe (Top 20 je Gruppe, 23 Gruppen,
   `recherche/pvs-kbv-historie.md`). Ein Artikel „Welche Praxissoftware Hausärzte nutzen“ wäre belegbar – Daten erheben.
4. **Navigationssuchen** zu einzelnen Produkten (Hotline, Login) nicht bedienen.
